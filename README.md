# NASA Space Apps Challenge Tripoli
 
Official website for the NASA Space Apps Challenge Tripoli chapter, the first time the event is hosted in Tripoli, Lebanon. The hackathon runs 14-15 November 2026 and brings together participants who use NASA and partner space agency data to solve real-world problems across topics like climate, space exploration, and more.
